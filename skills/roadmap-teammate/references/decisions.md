# 알아서 정할 때 (roadmap-teammate 7절)

외부 자산·라이브러리·AI 모델·외부 서비스를 넣거나 맡기기 전, 사용자 취향인 결정(제품을 쓰는 사람이 보는 것, 쓰는 외부 서비스 바꾸기)이 생겼을 때 읽는다. 절 번호는 [../SKILL.md](../SKILL.md)의 절이다.

## 라이선스·약관

라이선스·약관은 Claude가 먼저 본다.

- 외부 자산(모델·폰트·소리·아바타 등), 라이브러리, AI 모델, 외부 서비스를 넣거나 맡기기 전에 라이선스·약관 원문을 읽고 "상업 사용 · 재배포 · 표기 의무 · 쓰임 제한"을 한 줄씩 체크리스트나 브리프에 적는다.
- 사용자에게 확인을 넘기지 않는다. 사용자 몫은 법률 검토가 꼭 필요한 것(번역한 약관 문구, 애매한 조항)뿐이고, 그때도 무엇이 왜 애매한지 적어 넘긴다.

## 사용자 취향인 결정

"알아서"여도 선택 UI로 묻는다. 되돌릴 수는 있지만 사용자가 분명한 취향을 가진 것들이다.

- **제품을 쓰는 사람(게임이면 플레이어)이 보는 것**: 화면 문구, 보상·답례 같은 주고받는 것의 내용, 처음 흐름(첫걸음·튜토리얼) 순서, 이름 붙이기. 내부 구조·코드·데이터 형식은 Claude가 정한다.
- **쓰는 외부 서비스를 바꾸는 것**: 같은 일을 하는 무료 대안으로 바꾸기 등([external-setup.md](external-setup.md)).
- 물을 때 선택지 2~3개와 추천을 주고, 문구면 실제 문장을 선택지에 그대로 쓴다.
- 사용자가 자리를 비웠으면(10절) 제품을 쓰는 사람이 보는 것은 추천대로 하되 **보고 맨 위 "확인해 주세요"**에 바꾼 문장·내용을 그대로 보인다. 외부 서비스 바꾸기는 하지 않고 그 줄을 ⏸로 둔다.
