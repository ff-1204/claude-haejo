# 나누기 자세히 (roadmap-teammate 1절)

마일스톤 세션을 새로 만들거나 이어 맡길 때, 세션이 무거워졌을 때, 작은 일을 부모가 직접 할 때 읽는다. 절 번호(0절, 5절 등)는 [../SKILL.md](../SKILL.md)의 절이다.

## 마일스톤 세션

- **마일스톤 번호가 바뀌면 새 세션, 같은 마일스톤의 다음 줄은 그 세션에 이어 맡긴다.**
  - 새 세션(`"fresh"`)은 제목 앞에 마일스톤을 적는다(예: "M2 스크립트 불러오기"). 브리프에는 고정 규칙·worktree·커밋 꼬리표를 다시 적는다. 이전 세션이 하던 PR은 그 세션이 끝낸다.
  - 이어 맡길 때는 `SendMessage`로 보낸다. 그 세션이 일하는 중이면 그 턴이 끝난 뒤 맡긴다. 그래서 한 마일스톤 안의 줄은 차례로 돌고, 다른 마일스톤 세션과는 함께 돌 수 있다. 줄마다 기본 브랜치에서 새 브랜치를 만들고 PR도 따로 낸다(한 줄 = 브랜치 하나 = PR 하나).
- 세션 이름과 하는 일이 어긋나지 않게 하고, 긴 세션에 맥락이 쌓여 무거워지는 것을 막기 위해서다.

## 세션이 무거워졌을 때

- **세션이나 부모 대화의 앞부분이 요약되기 시작하면 새 세션으로 넘긴다.**
  - 하위 세션이면 다음 줄을 새 세션(`"fresh"`)에 맡긴다. 제목에 차례를 붙이고(예: "M2-2 저장 화면"), 브리프에는 이미 끝난 줄과 PR 번호만 요약해 적는다.
  - 부모 세션이면 이어 하기 메모를 고치고 새 부모 세션을 제안한다. 마일스톤이 끝났을 때도 같다([wrap-up.md](wrap-up.md) "마무리").

## 작은 일은 부모가 직접

도구 호출 열 번 안쪽으로 끝나고 한두 파일만 고치는 일(문구, 표시 조건, 순서 등)은 하위 세션을 만들지 않고 부모가 직접 한다.

- 브랜치·PR(13절)과 0절 권한은 그대로다. 요청 하나 = 브랜치 하나 = PR 하나이고, 머지는 5절 확인 뒤 0절 권한대로 한다.
- 화면·흐름이 크게 바뀌거나 저장 형식·경제 규칙을 건드리면 작은 일이 아니다. 하위 세션에 맡긴다.
- 머지한 PR 본문 "나중에" 칸에 쌓인 사소한 지적(5절)은 부모가 모아 PR 하나로 고친다([pr-merge.md](pr-merge.md) "검토 지적 나누기"). 양이 많아 작은 일이 아니면 하위 세션 하나에 맡긴다.
