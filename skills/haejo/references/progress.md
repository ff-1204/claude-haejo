# 진행 물음과 알림

사용자가 "진행중이니?", "남은 거?", "얼마나 걸려?"처럼 진행을 물을 때, "내 방식"에서 큰 단계 알림을 켰을 때 읽는다([../SKILL.md](../SKILL.md) 8절).

## 진행 물음 꼴

"진행중이니?", "남은 거?", "얼마나 걸려?"에는 늘 같은 꼴로 답한다. 자주 묻는 말이라 한 화면에 읽히게 쓴다. 숫자는 로드맵·체크리스트의 ✅ 수와 바뀐 파일을 직접 보고 적는다. 하위 세션을 쓰고 있으면 그 상태(`list_sessions` `{"linked": true}`)와 PR 목록도 직접 본다.

```
**지금**: M3-2 저장 화면 — 구현 중 (테스트 전)
**끝난 것**: M3 2/5
**남은 것**:
| 항목 | 예상 | 비고 |
|---|---|---|
| M3-3 불러오기 | 1시간 | |
| M3-4 서버 연결 | 3시간 | ⏳ 오래 걸림 |
**미룰 후보**: M3-4 서버 연결(오래 걸리고 다른 항목이 기대지 않음)
**정하실 것**: 없음 / 1) … 2) …
```

- 예상 시간은 비슷한 지난 일이 걸린 시간으로 어림한다. 모르면 "모름"이라고 쓰고 지어내지 않는다.
- **미룰 후보**: 오래 걸리거나, 사람 확인이 필요하거나, 다른 항목이 기대지 않는 것을 이유와 함께 보인다. 미룰지는 사용자가 정한다. 미루면 체크리스트에 ⏸와 이유를 적는다.

## 큰 단계 알림

"내 방식"에서 켰을 때만 한다. 기본은 끔이다.

- 켜져 있으면 마일스톤의 한 줄이 끝났을 때, 마일스톤이 끝났을 때, 사용자 몫이 생겨 멈췄을 때는 `PushNotification`(쓸 수 있으면)으로 한 줄을 보낸다. 예: "M3-2 끝, M3 3/5 · 다음 M3-3".
- 사용자가 묻지 않아도 휴대폰에서 알 수 있게 하려는 것이다. 작은 고침마다 보내지는 않는다.
