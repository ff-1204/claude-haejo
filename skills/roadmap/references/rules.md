# roadmap 스킬 공통 규칙

`roadmap`과 `roadmap-*` 하위 스킬이 모두 따른다.

## 문서 다섯 개

| 문서 | 기본 파일 | 쓰는 스킬 |
|---|---|---|
| 페르소나 (+ 핵심 경험·범위·문서 위치 머리) | `personas.md` | `roadmap-core`(머리), `roadmap-personas` |
| 시나리오 | `persona-scenarios.md` | `roadmap-scenarios` |
| 체크리스트 | 프로젝트에 있던 체크리스트, 없으면 `checklist.md` | `roadmap-map`, `roadmap-priority`(I00-00 순서) |
| 매핑·점수·우선순위 | `persona-checklist-map.md` | `roadmap-map`(머리), `roadmap-score`(1·2절), `roadmap-priority`(3~5절) |
| 로드맵 | `roadmap.md` | `roadmap-milestones` |

- 기본 위치는 저장소 루트(git이 아니면 현재 폴더)다. 다른 곳을 쓰면 `personas.md` 머리의 `> 문서:` 줄에 적는다. 모든 스킬은 이 줄을 먼저 읽는다.
- `personas.md`가 없으면 `**/personas.md`를 찾아본다. 그래도 없으면 아직 시작 전이다.
- 프로젝트에 체크리스트가 이미 있으면(`*checklist*.md`) 그것을 쓴다. 새로 만들지 않는다.

## 머리 줄

모든 문서는 맨 위 인용 블록에 이 줄을 둔다.

```
> 갱신: YYYY-MM-DD HH:MM (<무엇을 했는지 한 마디>)
> 근거: <무엇을 보고 썼는지>
```

- 문서를 고칠 때마다 `갱신:` 줄을 지금 날짜·시각으로 바꾼다. 상위 스킬은 이 값으로 어느 문서가 낡았는지 판단한다(같은 날 여러 번 고쳐도 가를 수 있게 시각까지).
- 날짜·시각은 셸에서 읽는다(`date '+%Y-%m-%d %H:%M'`).
- 체크리스트 `I00-00` 순서 줄도 순서를 바꿀 때만 같은 꼴의 날짜·시각을 고친다.
- 매핑 문서는 세 스킬이 나눠 쓰므로 절마다 시각을 따로 둔다. 1절 제목 바로 아래 `> 점수: YYYY-MM-DD HH:MM`(roadmap-score), 3절 제목 바로 아래 `> 순서: YYYY-MM-DD HH:MM`(roadmap-priority). 머리 `> 갱신:` 줄은 roadmap-map이 쓴 때다.

## 번호와 표시

- 체크리스트 번호는 `F01-02-03`처럼 계층으로 쓴다(대문자 1~3자 + 두 자리 숫자 마디). 프로젝트에 이미 쓰는 접두어가 있으면 그것을 쓴다.
- **번호는 절대 바꾸지 않는다.** 빠지면 "(삭제)", 합쳐지면 "(통합됨 → X)"로 표시한다.
- 상태: ✅ 확정·끝 · ⬜ 열림 · ⏸ 보류 · 🔄 바뀜 · 🆕 새것 · 📝 기록(순서·결정처럼 할 일이 아닌 줄). markdown `- [ ]`는 쓰지 않는다.
- 시나리오 단계: ✅ 지금 됨 · 🔜 계획됨(번호) · ❌ 계획에 없음. 일부만 된 단계는 ` / `로 나눠 조각마다 표시와 번호를 단다: `✅ (F02-01) / <부족한 부분> 🔜 (F02-04)`. 점수 스크립트가 조각마다 센다.
- 페르소나 번호는 두 자리(`01`)부터. 더할 때는 다음 번호를 쓴다.

## 쓰는 법

- 사용자의 언어로 쓴다(한국어 사용자면 한국어).
- 짧은 문장, 쉬운 말. 문서 안에서 다른 문서는 상대 링크로 잇는다.
- 한국어가 든 파일을 고칠 때는 인라인 셸 명령(`node -e`, heredoc) 대신 파일 쓰기·고치기 도구나 스크립트 파일을 쓴다.
- 이미 있는 내용은 지우지 않는다. 바꾼 것은 🔄, 더한 것은 🆕.

## 묻기

- 사용자에게 묻는 것은 선택 UI(`AskUserQuestion`)로 한 번에 묻는다. 추천을 첫 번째 선택지에 두고 라벨 끝에 "(추천)"을 붙인다.
- 상위 스킬이 정한 확인 지점이 아니면 묻지 않고 Claude가 정한다. 정한 것은 문서의 "정한 것"이나 "바뀐 기록"에 남긴다.

## 한 줄 보고

하위 스킬은 끝날 때 한 줄로 보고한다. 형식: `<단계 기호> <스킬 이름>: <숫자로 된 결과> · <바뀐 문서>`
예: `② roadmap-scenarios: 32명 169단계 · 🔜 61 · ❌ 4 · persona-scenarios.md`

## 하위 스킬을 혼자 불렀을 때

상위 `roadmap` 없이 불리면 **자기 문서만** 고친다. 한 줄 보고 뒤에 한 줄을 더한다(고친 것이 없으면 "바뀐 것 없음"):
`다음에 낡는 문서: <뒤 단계 문서들> — 이어 하려면 "<roadmap에 할 말>"`
예: `다음에 낡는 문서: 매핑·점수·우선순위·로드맵 — 이어 하려면 "점수 다시 계산해줘"`

## 바뀐 기록

"더해진 것만"·"바뀐 곳만"·"끝 표시" 모드로 문서를 고친 하위 스킬은 매핑 문서 "6. 바뀐 기록"에 그날 절(`### YYYY-MM-DD <무엇>`) 아래 한 줄을 더한다. 같은 플로우의 줄은 한 절에 모은다.
