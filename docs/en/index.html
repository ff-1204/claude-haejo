The whole flow

Seven steps.
It starts at the one you need.

It doesn't always begin at step one. Say the phrase shown next to a step and it starts there.

  1. RequestIt reads your request and picks the step to start from
  2. PlanIt imagines who will use it and sets the build order
    “Plan this from scratch”
  3. MockupYou see the screen in advance and ask for edits
    “Add this feature”
  4. ConfirmSay “go with this” and that mockup becomes the reference
  5. BuildIt builds what the confirmed mockup shows
    “Fix this bug”
  6. TestsIt runs it and compares with the mockup. If something is off, it goes back to building
    “Run the tests”
  7. MergeIt saves and merges only as far as you chose at the start
    “Merge it”

If you're worried

Three common questions.

“I can't code at all.”

Say what you want in words. Choices come as buttons.

“What if the AI does whatever it wants?”

It gets your OK on a mockup before building. Saving, publishing and merging go only as far as you chose.

“How do I know it was done right?”

It shows the test results and what it couldn't do, as they are. A second AI reviews risky changes.
