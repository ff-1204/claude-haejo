“다 했어요” 한마디로 끝내지 않아요.

  • 시험을 돌린 결과를 그대로 적어요
  • 시안의 항목마다 됐는지 비교해요
  • 위험한 변경은 다른 AI가 한 번 더 검토해요
  • 못 한 것도 숨기지 않고 적어요

전체 흐름

일곱 단계 중
필요한 곳부터 시작해요.

늘 처음부터 하지 않아요. 옆에 적힌 말을 하면 그 단계부터 시작해요.

  1. 요청말을 듣고 어느 단계부터 할지 정해요
  2. 계획쓸 사람을 상상하고 만들 순서를 정해요
    “처음부터 기획해줘”
  3. 시안만들 화면을 미리 보고 고쳐요
    “이 기능 넣어줘”
  4. 확정“이대로”라고 하면 그 시안이 기준이 돼요
  5. 만들기확정한 시안대로 만들어요
    “이 버그 고쳐줘”
  6. 시험돌려 보고 시안과 비교해요. 부족하면 만들기로 돌아가요
    “테스트 돌려줘”
  7. 반영처음에 고른 만큼만 저장하고 반영해요
    “반영해줘”

직접 정하는 단계이 말이면 여기서 시작

“처음부터 기획해줘”

쓸 사람을 상상해서, 무엇부터 만들지 계획표를 써요.

결과 예시: 달리기 기록 앱

쓸 사람주말에만 뛰는 직장인 외 4명
1단계지난 기록 보기 · 목표 정하기
2단계친구와 기록 비교
3단계달린 길 지도에 표시

“이 기능 넣어줘”

“이 버그 고쳐줘”

시안 없이 바로 고치고, 시험한 결과를 알려 줘요.

결과 예시

  • 저장 버튼이 안 눌리던 것 고침
  • 시험 12개 모두 통과
  • 못 한 것: 휴대폰에서 직접 눌러 보기

“로드맵대로 개발해줘”

계획표에 남은 일을 차례로 만들고 시험해요.

결과 예시: 1단계

  • 지난 기록 보기
  • 목표 정하기
  • 기록 지우기 (다음 차례)

“자러 갈게”

떠나기 전에 한 번만 묻고 계속 일해요. 정할 것은 모아 둬요.

결과 예시: 아침에 보는 화면

  • 끝난 일 4개
  • 정할 것 1: 첫 화면 문구 고르기
  • 정할 것 2: 완성본에 반영할지

“로드맵 어디까지 왔어?”

끝난 일과 다음 할 일만 짧게 알려 줘요. 아무것도 고치지 않아요.

결과 예시

1단계5/5
2단계2/5
3단계0/4

걱정된다면

자주 묻는 세 가지.

“코드는 하나도 몰라요.”

원하는 걸 말로 하면 돼요. 고를 것은 버튼으로 나와요.

“AI가 마음대로 하면 어떡하죠?”

만들기 전에 시안으로 확인받아요. 저장·공개·반영은 고른 만큼만 해요.

“제대로 됐는지 어떻게 알죠?”

시험 결과와 못 한 것까지 그대로 보여 줘요. 위험한 변경은 다른 AI가 한 번 더 검토해요.
